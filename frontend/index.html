The model understands only 300×300 grayscale EL images of single cells. It misses about 1 in 5 defective cells, and ordinary photos give meaningless results. Do not use it for real inspection decisions.

ResNet18 macro-F1 ranged from 0.844 to 0.881 across seeds. This demo uses one model (seed 1). Always predicting "healthy" scores 69% accuracy while finding no defects.

Limitations

  • No module IDs in the dataset, so cells from one panel may appear in several splits, which could inflate scores.
  • One data split, one dataset, one image type, cell-level only, no field testing.
